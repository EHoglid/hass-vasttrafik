Get started

Install in a few minutes

Install through HACS for updates, or copy the integration manually into your Home Assistant configuration.

01

Install

In HACS, open Integrations, search for Västtrafik Journey Planner, and download it. You can also copy custom_components/vasttrafik_timetable into your Home Assistant config/custom_components directory.

02

Create API credentials

Create an application at developer.vasttrafik.se and subscribe it to Planera Resa v4. Keep the Client ID and Client Secret available for the first setup.

03

Add your first stop

Restart Home Assistant, open Settings → Devices & services → Add integration, and select Västtrafik Journey Planner. Search for a stop, select it, and save the departure settings.

04

Add more stops

When adding another stop, the integration reuses the credentials from your existing Västtrafik entry. You only need to search and select the new stop.

Using HACS before catalogue inclusion?

Add EHoglid/hass-vasttrafik as a custom repository, choose Integration, then search for Västtrafik and download it.

The Lovelace experience

A board built for the wall.

The bundled card follows Home Assistant’s layout height, fills each page with rows that fit, and rotates through additional pages without manual templates.

dashboard.yaml

entity: sensor.lindholmen_next_departure
title: Lindholmen
size: m
show_departure_after: true
lines: "10, 12, 19, 21, X1"
page_seconds: 5

Configuration

Useful by default, adjustable when needed.

Each stop can configure:

  • Time span from 0 to 1440 minutes
  • Platforms and direction stop-area GID
  • Maximum departures per line and direction
  • API page size and optional occupancy data
  • Optional RFC 3339 start date and time
